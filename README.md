# منصة الشكاوى — إدارة الحج والعمرة، قسم الشكاوى

| الصفحة | الرابط | الدخول |
|---|---|---|
| **تقديم شكوى** | `main.html` | كلمة مرور عامة أو خاصة (يحددها الأدمن)، أو زر «تقديم شكوى مباشرة» |
| **نتيجة الشكوى** | `main.html#/result` | رقم الشكوى + رمز المتابعة |
| **الاعتراض** | `main.html#/objection` | رقم الشكوى + رمز الاعتراض |
| **الأدمن** | `main.html#/admin` | كلمة مرور الأدمن |
| **التقارير** | `main.html#/reports` | كلمة مرور الإدارة (لكل شخص) |

## طريقة العمل

1. **المشتكي** يكتب اسمه وصفته، رقم هاتفه، المشتكى عليه وصفته، عنوان الاعتراض ونصّه (أو يتحدث 🎤)
   ← يحصل على رقم الشكوى (مثل `1448-00001`) ورمز متابعة.
2. **الأدمن**: «المطلوب» (تنبيهات ذكية)، «الشكاوى» (جدول بالتصفية والتصدير)، «الجلسات»، «الروابط» (رسائل جاهزة للنسخ)،
   و«الإعدادات» (الموسم، التصنيفات، الصفات، قفل ملفات Excel، تصفير المنصة).
3. **الحالات**: جديد ← قيد المراجعة ← جاري المتابعة ← مغلقة.
4. **المواسم**: كل موسم (1447، 1448…) يبدأ ترقيمه من 1؛ يُغيَّر من «الإعدادات».

## التشغيل لأول مرة

1. Supabase ← **SQL Editor** ← الصق `supabase/schema.sql` كاملاً ← **Run** (غيّر كلمة مرور الأدمن في القسم الأخير قبل التنفيذ).
2. رمز التصفير: `select public.set_reset_code('رمز-من-8-أحرف');`
3. افتح `main.html#/admin`.

## تعديل الكود (للمطوّر)

- الكود في `src/app.jsx`، والصفحة تحمّل `app.js` الجاهز (أسرع على الجوال).
- بعد أي تعديل: `python build.py` ← يولّد `app.js` ويحدّث رقم النسخة في `main.html` ← ارفع الملفات.

## الحماية

- الموقع لا يقرأ الجداول مباشرة؛ كل عملية تمر بدالة تتحقق من كلمة المرور.
- لا يوضع مفتاح `service_role` في `config.js` إطلاقاً.
