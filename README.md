# منصة شكاوى لجنة الحج

ثلاث صفحات فقط، وكل صفحة تُفتح برمز:

| الصفحة | الرابط | الرمز |
|---|---|---|
| **المشتكي** | `main.html` | كلمة مرور من 4 أرقام، خاصة بكل شخص، تُستخدم مرة واحدة |
| **الإدارة** | `main.html#/admin` | رمز الإدارة (تعيّنه أنت من Supabase) |
| **التقارير** | `main.html#/reports` | رمز خاص من 8 أحرف لكل شخص، يمكن إيقافه |

## طريقة العمل

1. **الشخص يراسلك على واتساب** ← تفتح الإدارة ← تبويب «كلمات مرور المشتكين» ← «توليد كلمة مرور» ← «إرسال واتساب».
2. **المشتكي** يفتح الرابط ← يدخل كلمة المرور ← يكتب اسمه واسم المشتكى عليه ونص الاعتراض ← «تم تسجيل الشكوى بنجاح».
   رقم الشكوى (`HJ-2026-00001`) وتاريخها وكلمة المرور المستخدمة تُسجَّل تلقائياً، وحالتها تبدأ «معلقة».
3. **في الإدارة** (تبويب «الشكاوى»): التصنيف، الترحيل (مُحالة إلى)، الحالة (معلقة / مفتوحة / متأخرة / مغلقة)، النتيجة، وتاريخ الإغلاق.
4. **التقارير:** من تبويب «رموز التقارير» تضيف الشخص فيُولَّد له رمز ترسله له. يرى أعداد الشكاوى (الإجمالي، المغلقة، المفتوحة) لفترة يختارها، وجدولاً بالحالة والرقم والأسماء والموضوع والنتيجة وتاريخ الإغلاق.

## التشغيل

1. Supabase ← **SQL Editor** ← الصق `supabase/schema.sql` كاملاً ← **Run** (إن ظهر تحذير اضغط «Run this query»).
2. عيّن رمز الإدارة (8 أحرف على الأقل):
   ```sql
   select public.set_admin_password('رمز-الإدارة');
   ```
3. افتح `main.html#/admin`.

## الحماية

- الموقع لا يقرأ الجداول مباشرة؛ كل عملية تمر بدالة تتحقق من الرمز.
- إيقاف المحاولات الخاطئة وسجل المحاولات مُلغيان بطلب الإدارة.
- كلمة مرور المشتكي تتوقف بعد تقديم شكواه، ويمكنك إلغاء أي كلمة لم تُستخدم.
